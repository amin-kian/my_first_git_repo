🛍️ Shopino | Online Shopping Website

A simple and responsive online shopping website built with HTML, CSS, and JavaScript.

📌 About The Project

Shopino is a front-end e-commerce project designed to provide users with a simple and enjoyable online shopping experience.

Users can browse products, view product details, add items to their shopping cart, and manage their orders.

✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Product listing and product details
* Add and remove products from the shopping cart
* Update product quantities
* Calculate total price automatically
* Search products by name
* Filter products by category
* Modern and user-friendly interface

🛠️ Technologies Used

* HTML5 – Page structure
* CSS3 – Styling and responsive layout
* JavaScript (ES6+) – Application logic and interactivity
* Font Awesome – Icons
* Google Fonts – Typography

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository

git clone https://github.com/username/shopino.git

2. Navigate to the Project Directory

cd shopino

3. Run the Project

Open the index.html file in your browser.

Alternatively, you can use the Live Server extension in Visual Studio Code.
